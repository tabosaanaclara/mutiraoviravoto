Jogo Vira-voto

Bora pra rua conversar com as pessoas usando o jogo de cartas Nosso Baralho.

Cada carta faz uma pergunta simples e abre uma boa conversa.

Vamos levar os fatos para os próprios eleitores julgarem o que é bom e o que é ruim, com QR code para checar os fatos.

Nos encontramos

3

Nos dividimos em duplas

Ninguém vai sozinho. Cada pessoa tem um parceiro para dividir a conversa.

4

Rumo aos pontos de ônibus

Jogamos com quem estiver esperando o ônibus e deixamos o QR code para checar os fatos.
